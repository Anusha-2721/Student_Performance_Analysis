# 📊 Student Performance Analysis

## 📌 About the Project

Student Performance Analysis is a Python-based data analysis project developed using **NumPy, Pandas, and Matplotlib**. The project analyzes student marks, calculates average performance, identifies the top-performing student, and determines whether a student has passed or failed based on the average marks.

## 🛠️ Technologies Used

* 🐍 Python
* 🔢 NumPy
* 🐼 Pandas
* 📊 Matplotlib
* 📄 CSV

## ✨ Features

* Read student data from a CSV file
* Calculate average marks of each student
* Analyze student performance
* Identify the top-performing student
* Determine Pass/Fail status
* Visualize student performance using graphs

## 📂 Dataset

The project uses a CSV file containing marks for different subjects:

* Python
* Java
* C
* Cyber Security
* Frontend
* Backend
* Database

## 🔄 Working Process

```text
CSV Dataset
    ↓
Load Data using Pandas
    ↓
Process Student Marks
    ↓
Calculate Average
    ↓
Find Top Student
    ↓
Determine Pass / Fail
    ↓
Visualize Data using Matplotlib
```

## 📈 Data Analysis

The project performs the following analysis:

1. Calculates the average marks of each student.
2. Finds the student with the highest average.
3. Checks the student's result based on the pass mark.
4. Displays the analyzed data.
5. Creates visualizations to understand student performance.

## 📊 Visualization

Matplotlib is used to represent the analyzed student performance through graphs and charts, making the results easier to understand.
